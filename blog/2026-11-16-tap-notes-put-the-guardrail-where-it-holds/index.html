Tap Notes: Put the Guardrail Where It Holds

November 16, 2026

Several of today’s reads are the same argument in different clothes: a constraint only counts if it lives in a layer the thing being constrained can’t talk its way past. A prompt isn’t that layer. A secret sitting in page-reachable code isn’t either. A runbook, a sandbox, a deadline in the harness: those are.

Where constraints live

Universal XSS in uBlock Origin from website-driven element picker

A malicious page could leak the extension’s internal UUID, load the element picker in an invisible iframe, drive it over postMessage, and inject a trusted filter that runs arbitrary JavaScript on any site. The fix added a shared secret between the content script and the picker.

Why it matters: The ingredients are a web-accessible resource, a postMessage handler with no origin check, and a code path that trusts its input by default. The newline smuggled through an options field is the nasty bit. The funniest part is that the ad-blocking fetch hook leaks the UUID, so the guardrail is the exfil channel. The password fix works, but it patches the symptom: the handler should check origins instead of trusting a secret that lives in page-reachable code. Also worth noting that an AI model found the bug and another wrote the proof of concept. Bug-finding is agent work now.

Prospero: A new coding harness for a more civilized age (from October 2026)

A C++ coding harness with a Dear ImGui interface that uses roughly two orders of magnitude less memory than web-stack alternatives. It supports subagents, remote headless runs and tool calling.

Why it matters: Skip the GUI and read the principles. “Never wait forever” means every operation has a deadline, and a permission prompt that times out becomes a denial. An unattended agent degrades instead of deadlocking. Kill whole process trees, not just the parent. And the permissions section is honest: they gently remind the agent of your wishes, and anything that can write and run code has already won. Real isolation belongs at the container or harness level. Almost nobody designs for these failure modes on purpose.

GitHub: strangerstudios/pmpro-stack

Stranger Studios open-sourced its hardened WordPress hosting stack. An Ansible playbook plus a provisioning CLI takes a droplet and DNS tokens to a working Paid Memberships Pro site, or hands the job to a coding agent through an AGENTS.md runbook.

Why it matters: Full disclosure: this is my own house. The pattern is still the right one for agent-driven infrastructure. Don’t let the agent improvise server setup. Give it a curated playbook and let it drive. Constraint by runbook, not by model goodwill. The origin firewall that only answers the CDN proxy and the cache exclusions for checkout and member pages are production scars written down. I’d like to see a self-hosted agent run it end to end and find where the runbook breaks.

Show your work

GitHub: lm_understand-logs

The complete logs behind a blog post claiming LLMs can understand and write neural network weights: 1,125 turns, run through Codex CLI with built-in tools disabled, and audited as tool-free from the event stream. The few experiments that allowed code used one Python block per turn in a network-free sandbox.

Why it matters: My standing complaint about agent research is that nobody ships the logs, so you can’t tell steering from vibe-coding. This repo is the counterexample. It has a per-turn audit flag, the sandbox spec in the repo, and a README mapping each figure to a file. The weight edits are published as exact diffs against public base weights, so the claim is falsifiable by construction. If I ever publish agent work, this is the format to copy.

No AI Slop: A Manifesto

An Agile-Manifesto-shaped statement from AIE Code Summit attendees about low-effort AI output. It defines slop, then lists resolutions: own the intent, review what matters, label AI-assisted work, fix systems instead of patching outputs.

Slop is work produced with less effort than it takes the consumer to understand.

Post to X

Why it matters: The Agile homage is a little precious. The definition isn’t. Generation cost goes to zero while review cost stays constant, and a swarm of agents can outproduce any human’s review bandwidth. Worse, the next agent reads the previous slop. “When a mistake shows up twice, fix the system, not the output” is a decent job description for anyone running agents. I also like that it allows unreviewed output when the stakes are low. Purity tests don’t scale.

Surface area

Lovable apps expose passport details and more than 200K private messages

A security audit of roughly 159K apps built on an AI app builder found exposed passport data and over 200K unauthenticated private messages.

Why it matters: I haven’t dug into every failure pattern yet, but the headline shape is predictable: generating an app is now trivial, and knowing what a database policy does is not. The builder produces the surface area; nobody owns the guardrail. Read it for the specific patterns, then check what your own generated code exposes by default.

One more thing

Brave Search API now accepts agentic payments via the x402 protocol: no API keys. The agent gets an HTTP 402, settles the request in USDC, and retries, with Brave running its own facilitator. It’s the first major production per-request payment flow for agents I’ve seen, and it’s worth watching whether the billing layer becomes another place where constraints live or leak.

Put the lock in the layer the lockpick can’t reach. 🪨
