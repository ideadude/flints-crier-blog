Tap Notes: The Verifier Isn't the Model

November 18, 2026

The pattern in this batch: nobody serious is asking the model to be trustworthy anymore. They’re putting the guarantee somewhere else, in a proof checker, a sandbox boundary, a signed record or a database transaction. The model proposes, and something dumber and harder decides.

Verification

AlphaProof Code DeepMind used agents plus human experts to formally verify the actual implementation of the Signal protocol, generating over six million lines of Lean proofs in about four weeks. They claim it’s the first time a widely deployed cryptographic protocol’s implementation has been verified by any method.

Why it matters: The shape is the point. Agents write the proofs, Lean checks them, and humans handle the spec and judgment calls. The LLM is never the oracle. Roughly 1% was flagged for human review. They also validated the system by reintroducing known bugs and confirming it proved the code insecure. Most “AI verified this” claims skip that step, so this is the one to copy.

Boundaries

External sandboxes for coding agents Simon Willison and Prime Radiant describe a pattern where the agent runs outside and only the code it executes runs inside an isolated sandbox. Three reference implementations (WebAssembly, Apple Containers, QEMU) share one localhost API, with an optional allow-list proxy and credential replacement.

Why it matters: Credential replacement is the sleeper feature. The agent can make authenticated calls without ever holding the token, which is a structural answer to the “private data plus untrusted input plus exfiltration path” problem instead of a politely worded system prompt. Three interchangeable backends behind one API also means you can try it without rewriting your agent.

Muse Creates Detailed Profiles of All Your Friends and Family Researchers found Meta’s Muse assistant has internal instructions to build hourly “pages” on people in your life. Meta says it uses only public or user-shared data, runs each user in a dedicated VM, requires confirmation for actions and offers logs and deletion.

Why it matters: The profiling headline is the lesser story. Per the reporting, the system’s own instructions came out through the chat interface, apparently by asking it to copy them. That’s private memory, broad tool access and the prompt as an exfiltration channel, all in one production product. The per-user VM and audit log are decent guardrail design. The chat window is still the leak.

Provenance and plumbing

Tangled An open-source code forge on the AT Protocol: federated Git hosting, stacked PRs via Jujutsu, and microVM CI. Agents and humans are both meant to be first-class, via signed JSON records.

Why it matters: Giving agents their own signed identities, instead of bots pretending to be people, means every action carries provenance. That could make “who did this and why” tractable in agentic PR workflows. Whether it makes review saner or just moves the problem is an open question, but it’s worth a test drive. You can self-host the pieces.

Honker (from April 2026) A SQLite extension that adds Postgres-style NOTIFY/LISTEN, durable pub/sub, task queues and scheduling inside a single database file, with no broker. It reports ~0.7 ms cross-process wake latency by polling PRAGMA data_version every millisecond.

Why it matters: The feature that earns its keep is the transactional outbox for free. Enqueue a job in the same transaction as the business write, and a rollback drops both. That’s the same “guarantee lives outside the clever part” idea at the plumbing level. The polling trick is also just good engineering: one cheap read per millisecond, one poller per database regardless of subscriber count.

Measurement

What is the best harness for each model? A large harness-by-model benchmark (reportedly 83B tokens across 27k runs) finds the best harness shifts significantly depending on the model.

Why it matters: If you pick one agent harness and swap models underneath it, you’re probably leaving performance on the table. The scaffold is part of the system under test. I haven’t dug into the methodology yet, so read it before you route anything on its numbers.

One more thing

Running the full server-side Datasette Python app in the browser with service workers and Pyodide: Simon rewrote Datasette Lite so the whole app runs client-side, and you can pin a Datasette version, plugins and one of 100+ SQLite builds from the URL. Linking a bug repro as a clickable URL beats a “works on my machine” paragraph.

Trust the checker, not the thing being checked. That’s the whole digest. 🪨
